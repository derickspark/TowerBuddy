# 🧗 TowerBuddy (NS-Tower)

끝없는 탑을 오르는 웹 게임. 1997년 Windows 게임 **NS-Tower** (Nagi-P Software)의 점프 메커니즘에서 영감을 받았습니다.

## ▶️ 플레이

**[여기서 바로 플레이 →](https://derickspark.github.io/TowerBuddy/)**

## 🎮 조작법

- 캐릭터는 **좌우로 자동**으로 움직입니다. 벽에 부딪히면 방향이 바뀝니다 (점프 중에도).
- `SPACE` / 마우스 / 터치를 **누르고 있으면 파워 충전**, 떼면 점프!
- 오래 누를수록 높이 뛰지만, **너무 오래 누르면 파워가 0으로** 떨어집니다.
- 발판을 놓쳐 화면 **아래로 떨어지면** 게임 오버.

## 🧱 발판 종류

| 색 | 종류 | 설명 |
|----|------|------|
| 🟦 파랑 | 일반 | 평범한 발판 |
| 🟧 주황 | 컨베이어 | 화살표 방향으로 밀림 |
| 🟪 보라 | 이동 | 좌우로 움직임 |
| 🟥 빨강 | 붕괴 | 밟고 점프하면 부서짐 |

높이 올라갈수록 특수 발판 비중이 늘고, 상위 5개 점수는 브라우저에 저장됩니다.

## 🛠 기술

의존성 없는 **단일 HTML 파일** (Canvas 2D + Vanilla JS). 데스크톱·모바일 모두 지원.
